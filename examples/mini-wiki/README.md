# Mini Wiki Snapshot

A complete, hand-curated mini-wiki built from two short synthetic articles.
The point of this directory is to make CLIO's output shape concrete: instead
of reading prose about "leaf-first ingest produces a wiki/sources page and a
concept page", you can open the actual files and see exactly what they look
like.

## Layout

```
examples/mini-wiki/
├── raw/
│   ├── articles/
│   │   ├── leaf-first-merge.md     # synthetic source #1 (prose)
│   │   └── raw-immutability.md     # synthetic source #2 (prose)
│   └── code/
│       └── throttle/               # mixed code + image leaf
│           ├── throttle.ts         # synthetic source #3 (code)
│           └── sliding-window.svg  # synthetic source #4 (diagram)
└── wiki/
    ├── concepts/
    │   ├── leaf-first-merge-pass.md
    │   ├── raw-immutability.md
    │   └── sliding-window-rate-limit.md
    ├── sources/
    │   ├── articles/
    │   │   ├── leaf-first-merge.md
    │   │   └── raw-immutability.md
    │   ├── code/
    │   │   └── throttle/
    │   │       └── index.md         # directory-level summary of the mixed leaf
    │   └── index.md                # generated by scripts/build-sources-index.mjs
    ├── index.md
    └── log.md
```

## What to Compare

- `raw/articles/<file>.md` versus `wiki/sources/articles/<file>.md`
  — see the per-source summary structure: frontmatter facets
  (`source_kind`, `source_date`, `topics`, `concepts`, `status`),
  gist + key points, quotes, wiki connections, provenance.
- `wiki/concepts/<concept>.md` — the synthesis layer that cross-links source
  summaries. Notice how the concept page cites a source page rather than the
  raw file directly.
- `raw/code/throttle/` versus `wiki/sources/code/throttle/index.md` — a **mixed
  code + image leaf**. The directory-level source page summarizes the `.ts`
  module *and* records the `.svg` diagram as a caption + alt-text (read
  text-first, never embedded as a binary) per the
  [`wiki-images`](../../.agents/skills/wiki-images/SKILL.md) skill. This is the
  Code Wiki + multimodal output shape.
- `wiki/sources/index.md` — produced verbatim by
  `node scripts/build-sources-index.mjs --root examples/mini-wiki`. Re-run
  the script after editing any frontmatter to see the catalog update.
- `wiki/index.md` — hand-maintained category catalog.
- `wiki/log.md` — append-only operation log (`ingest`, `merge`,
  `sources index regen` entries).

## Regenerating the Source Catalog

```bash
node scripts/build-sources-index.mjs --root examples/mini-wiki
node scripts/build-sources-index.mjs --root examples/mini-wiki --check
```

The first command rewrites `wiki/sources/index.md` deterministically. The
second exits non-zero if the file is out of date — useful as a CI gate.

## What This Snapshot Is Not

- It is **not** the output of an actual `/ingest` run. The text was authored
  by hand to demonstrate the target shape, not to benchmark any specific
  CLI's behavior.
- It is **not** a complete `wiki/.progress/ingest/.state.json` or per-leaf
  lock simulation. State files and locks are runtime artifacts; this
  snapshot only shows the user-visible result.
- It does **not** include a `wiki/graph/` build. Graph artifacts come from
  `wiki-graphify update` after ingest; see `wiki/graph/GRAPH_REPORT.md` in
  a real run.
