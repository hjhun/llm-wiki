# CLIO v0.1.0

First public release of CLIO, a local-first LLM Wiki workbench.

## Highlights

- Local-first Markdown wiki rooted in `raw/` and `wiki/`.
- Browser UI with Chat, Explorer, Graph, and Settings tabs.
- Agent-operated `/ingest`, `/query`, `/lint`, and graph workflows.
- Incremental leaf-first ingest and graph update rules through project-local skills.
- Global `graphify` integration for knowledge graph build/update flows.
- Remote installer:

```bash
curl -fsSL https://raw.githubusercontent.com/hjhun/llm-wiki/v0.1.0/scripts/install.sh | bash -s -- --start
```

## Release Assets

No custom binary assets are required. GitHub's generated source archives are the
distribution artifact for this release.
